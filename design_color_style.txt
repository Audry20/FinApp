4. UI Style Rules 
• Use rounded cards and controls with soft shadows. 
• Keep the background almost black with a deep green tint. 
• Use bright mint green sparingly for actions, balances and active states. 
• Use white only for primary information; use muted sage green for secondary information. • Use red only for expenses or negative financial values. 
• Glassmorphism should remain subtle: dark translucent surfaces, light borders and backdrop blur. • Avoid excessive transparency; the reference is closer to dark neumorphism than pure glassmorphism. 
5. Useful Gradient 
Primary gradient: #55A65D → #76E381 → #89E692 
Use it for balance cards, hero areas, primary CTAs and selected states.
